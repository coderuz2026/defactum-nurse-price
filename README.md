# De Factum — прайс для медсестёр

Прайс-лист для мобильного приложения выездных медсестёр De Factum Laboratories.
Приложение при запуске проверяет `data/version.json` и, если версия изменилась, скачивает свежий `data/prices.json`.

## Файлы

| Файл | Что внутри |
|---|---|
| `data/prices.json` | Рабочий прайс: категории и услуги с ценами (UZS) |
| `data/version.json` | Версия прайса и количество услуг — приложение сверяет её при запуске |
| `data/prices_excluded.json` | Что не попало в прайс и почему (цена 0, корпоративные, дубли) |
| `tools/build_prices.py` | Скрипт: экспорт из Aurora (.xlsx) → `prices.json` |

## Как обновить цены

1. В Aurora: **Продукты → выделить все → Действие → Экспорт** с полями
   `Имя`, `Категория`, `Нумерация`, `Продажная цена`, `Цвет приоритета`.
2. Собрать прайс:
   ```bash
   pip install openpyxl
   python3 tools/build_prices.py export.xlsx data/prices.json
   ```
3. Поменять дату в `"version"` (в `prices.json` и `version.json`) и сделать commit/push.
4. У медсестёр цены обновятся сами при следующем запуске приложения.

Ссылка, которую читает приложение:
`https://raw.githubusercontent.com/coderuz2026/defactum-nurse-price/main/data/prices.json`

## Формат `prices.json`

```json
{
  "version": "2026-11-10",
  "currency": "UZS",
  "categories": [{ "id": 24, "code": "01", "name": "Гематологические исследования" }],
  "items": [{ "id": 123, "name": "Общий анализ крови развернутый", "cat": 24, "price": 80000 }]
}
```

`id` услуги — это id продукта в Aurora (`product_product_<id>`), по нему потом свяжем анализы с контейнерами (пробирками).

## Что фильтруется

- позиции с ценой 0 (абонементы, льготы);
- корпоративные позиции `UzAirways_`;
- дубли по названию.

## Проверка расчётов

```bash
node tools/calc_test.js
```

Тест берёт функции прямо из `index.html` и проверяет на реальном прайсе: суммы по пациенту и выезду, скидку, выезд на дом, группировку пробирок, уникальность штрихкодов и id услуг. Запускать после каждого обновления прайса.

## Сканирование листа заказа

Кнопка «Сфотографировать лист заказа» читает распечатку заказа из Aurora: ФИО, дату рождения, телефон, ID пациента, ID счёта, адрес и список услуг. Распознавание идёт на самом телефоне (Tesseract в `vendor/tesseract`), фото никуда не отправляется.

- Строки листа сопоставляются с `data/prices.json` по названию.
- Сумма найденных строк сверяется с «Итого» на листе. Если не сошлась — приложение перечитывает таблицу крупнее и, если всё равно не сошлось, показывает предупреждение.
- Штрихкод пробирки = ID счёта + номер контейнера (как в Aurora).
- Скорость: фото обрезается по листу и приводится к ширине 1700 px, линии таблицы стираются; на телефонах с 4+ ядрами верх и низ листа читаются двумя потоками одновременно.
- Контроль: блок «ФИО, дата рождения, телефон» читается второй раз крупно; если два чтения расходятся, приложение показывает ошибку.
- Разбор текста — в `scan.js`, тесты на вымышленном листе — в `tools/calc_test.js`.

## История, отчёт, чек, наборы (с версии 1.28)

- **История выездов и отчёт за смену** — экран «Выезды и отчёт»: по дням, с разбивкой по способу оплаты (наличные, карта, Click, Payme). Отчёт отправляется картинкой или копируется текстом. Закрытый выезд запоминает свою сумму, поэтому смена цен не меняет прошлые отчёты.
- **Чек клиенту** — кнопка на экране «Показать клиенту», отправляется картинкой.
- **Подготовка к анализам** — короткие общие подсказки (`PREP` в `index.html`). Это общие правила; перед использованием их должен проверить врач лаборатории.
- **Наборы анализов** — готовые (`SETS` в `index.html`, по id услуг из прайса) и свои, сохранённые медсестрой.

## Забор: «Взято» и «Не удалось» (с версии 1.30)

- На экране «Пробирки» у каждой пробирки две кнопки. **Взято** — запоминается время забора, оно печатается на этикетке («Взято 13.11.2026 09:41»). **Не удалось** — нужно выбрать причину; анализы этой пробирки убираются из суммы клиента, этикетка на неё не печатается. Анализ, которому нужны две пробирки, выпадает, если не взята любая из них.
- На экране выезда напоминание: когда взят материал и сколько прошло. Если задан срок доставки, показывается «Доставить до …» и опоздание.
- Сроки доставки — `DELIVERY` в `index.html`: номер контейнера → часы, например `{ 4: 2 }`. Пока пусто, заполнить по требованиям лаборатории.

## Этикетка 40×30 мм (с версии 1.34)

Первичная этикетка выезда — таблица без штрихкода и без списка анализов, чтобы её нельзя было спутать с этикеткой Aurora: чёрная шапка «DE FACTUM · ВЫЕЗД» с номером заказа (номер счёта + контейнер), дальше пациент, дата рождения, пробирка (номер контейнера и цвет) и время забора («Взято») или выезда.
