# De Factum — прайс для медсестёр

Прайс-лист для мобильного приложения выездных медсестёр De Factum Laboratories.
Приложение при запуске проверяет `data/version.json` и, если версия изменилась, скачивает свежий `data/prices.json`.

## Файлы

| Файл | Что внутри |
|---|---|
| `data/prices.json` | Рабочий прайс: категории и услуги с ценами (UZS) |
| `data/version.json` | Версия прайса и количество услуг — приложение сверяет её при запуске |
| `data/prices_excluded.json` | Что не попало в прайс и почему (цена 0, корпоративные, дубли) |
| `tools/build_prices.py` | Скрипт: экспорт из Aurora (.xlsx) → `prices.json` |

## Как обновить цены

1. В Aurora: **Продукты → выделить все → Действие → Экспорт** с полями
   `Имя`, `Категория`, `Нумерация`, `Продажная цена`, `Цвет приоритета`.
2. Собрать прайс:
   ```bash
   pip install openpyxl
   python3 tools/build_prices.py export.xlsx data/prices.json
   ```
3. Поменять дату в `"version"` (в `prices.json` и `version.json`) и сделать commit/push.
4. У медсестёр цены обновятся сами при следующем запуске приложения.

Ссылка, которую читает приложение:
`https://raw.githubusercontent.com/coderuz2026/defactum-nurse-price/main/data/prices.json`

## Формат `prices.json`

```json
{
  "version": "2026-11-10",
  "currency": "UZS",
  "categories": [{ "id": 24, "code": "01", "name": "Гематологические исследования" }],
  "items": [{ "id": 123, "name": "Общий анализ крови развернутый", "cat": 24, "price": 80000 }]
}
```

`id` услуги — это id продукта в Aurora (`product_product_<id>`), по нему потом свяжем анализы с контейнерами (пробирками).

## Что фильтруется

- позиции с ценой 0 (абонементы, льготы);
- корпоративные позиции `UzAirways_`;
- дубли по названию.

## Проверка расчётов

```bash
node tools/calc_test.js
```

Тест берёт функции прямо из `index.html` и проверяет на реальном прайсе: суммы по пациенту и выезду, скидку, выезд на дом, группировку пробирок, уникальность штрихкодов и id услуг. Запускать после каждого обновления прайса.
